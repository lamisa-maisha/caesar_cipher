# 🔐 Caesar Cipher

A classic encryption tool built as part of the [FreeCodeCamp]() curriculum. This project implements the Caesar cipher, shifting letters of the alphabet by a fixed number of positions to encode or decode messages.

## 📝 Description

The Caesar cipher is one of the simplest and most widely known encryption techniques. Each letter in the plaintext is shifted a certain number of places down or up the alphabet. This project provides a user-friendly interface to:

## 🛠️ Technologies Used

- Python
  
## 📋 Features

- Text input area
- Shift key selection (slider or number input)
- Instant output display
- Handles both uppercase and lowercase letters
- Ignores non-alphabet characters (numbers, punctuation, spaces stay the same)

## 🧪 How to Use

1. Enter your message in the input box.
2. Choose a shift number (1–25).
3. Click *Encode* to encrypt or *Decode* to decrypt.
4. View the result instantly.

## 🧠 Example

- *Plaintext*: hello World
- *Shift*: 3
- *Ciphertext*: uryyb jbeyq
